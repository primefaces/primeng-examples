# PrimeNG examples

Example projects for [PrimeNG](https://primeng.dev). Each folder is a complete Angular app with its own README, and all of them open on StackBlitz.

## Starters

Both starters build the same small dashboard, one with the Aura preset alone and one with Tailwind CSS added.

| Example | Styling | Open |
| --- | --- | --- |
| [primeng-quickstart](./primeng-quickstart) | Aura preset | [StackBlitz](https://stackblitz.com/github/primefaces/primeng-examples/tree/main/primeng-quickstart) |
| [primeng-quickstart-tailwind](./primeng-quickstart-tailwind) | Aura preset and Tailwind CSS v4 | [StackBlitz](https://stackblitz.com/github/primefaces/primeng-examples/tree/main/primeng-quickstart-tailwind) |

## Run an example

```bash
cd primeng-quickstart
npm install
npm start
```

Each example has its own README with the files to look at.
